# Matinha Theme Park Horror Game

Godot 4.7 project. Open the folder in Godot and press F5 to walk around the park.

Controls: WASD to move, mouse to look, Shift to run, Space to jump, Esc to free the mouse (click to recapture).

## Map

`scenes/park_map.tscn` is a plain blockout of Matinha laid out from the reference aerial photo (about 1 px = 0.1 m). Everything solid has collision. No rides are built or scripted yet; the round areas are only the pads and blue curbs seen in the photos.
